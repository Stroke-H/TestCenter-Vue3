# ChangeLog - Defect Management

## 2026-09-28

### Fixed
- **Feishu Sync Retry Limit**: 飞书缺陷同步失败后最多自动尝试 5 次；达到上限后保留同步失败状态与最后错误，不再由后台任务持续重试。用户在缺陷详情手动重新同步时会重置计数并开启一轮新的尝试。

## 2026-09-21

### Added
- **Manual Default Member Addition**: 权限管理的默认成员属性区域新增“添加默认成员”入口，可从尚未配置的平台账号中选择成员和默认测试、开发或产品属性；默认成员列表仅展示已实际保存的配置，不再把所有未配置账号自动显示为测试人员。

## 2026-09-18

### Added
- **Feishu Project Inbound Refresh (v1)**: 缺陷管理“刷新数据”支持按当前用户独立 OAuth 身份增量读取海外短剧与番茄短剧空间最近变更的缺陷。平台以飞书 `work_item_id + project_key + work_item_type` 作为稳定映射键；平台曾同步记录的编号仅用于补建历史映射，不要求飞书原生记录填写平台编号。刷新会新增、更新或跳过记录，并对平台/飞书双边同时修改进行冲突保护；所属项目无法从描述、TTmins 标题前缀或唯一“业务线 + 平台”组合确定时只列为待确认，不自动误导入。
- **Tomato Drama Feishu Defect Routing**: 缺陷同步根据项目配置的“所属空间”自动路由；番茄短剧项目使用番茄短剧空间的项目标识、缺陷模板和业务线叶子选项，海外短剧项目继续保持原有映射，避免跨空间写入或字段选项校验失败。
- **Strict Feishu Operator Assignment**: 平台缺陷选择处理人后，飞书同步会按同名在职用户精确匹配，先移除工作项的全部旧经办人，再指派当前处理人；查无此人、出现同名歧义或空间无权时，同步任务明确标记失败并保留原因。
- **Per-user Feishu Project OAuth**: 头像菜单新增“飞书项目授权”，每个平台用户通过设备授权流程独立注册并绑定自己的 OAuth Client、飞书身份、访问令牌和刷新令牌，任何用户重新授权或失效均不覆盖其他用户。访问与刷新凭证经 AES-GCM 加密后按平台账号隔离存储，缺陷同步优先使用提交人本人身份创建记录；服务每 15 分钟检查凭证并在访问令牌到期前 30 分钟自动续期，以支持一次确认后至少按月持续使用。除保留 `minghong` 的历史凭证兼容外，其他用户未授权、授权失效或无空间权限时均明确标记同步失败，不再静默共用黄明宏身份。

### Fixed
- **Stable OAuth Credential Encryption**: OAuth 密钥改为独立持久化在数据库配置目录的本机私密文件，不再随数据库密码、MCP Token 或进程环境变化；兼容迁移已生成的旧版客户端密文，并在尚无用户授权数据时安全重建不可解密的客户端配置，修复授权时报 `cipher: message authentication failed`。

## 2026-09-17

### Added
- **Feishu Project Defect Sync**: 所属空间为“海外短剧”的项目在缺陷创建、编辑、状态调整和批量处理成功后，自动通过现有飞书项目 MCP 凭证异步同步到“缺陷管理”工作项；同步任务持久化保存并支持指数退避重试，不阻塞平台缺陷操作，也不会回扫历史缺陷。
- **Feishu Sync Visibility**: 缺陷详情展示等待中、同步中、成功或失败状态，成功后可直接打开飞书工作项，失败时拥有编辑权限的用户可手动重新同步。
- **Per-defect Feishu Sync Control**: 新建缺陷默认勾选“是否同步到飞书空间”，可按单条或批量创建决定是否进入同步队列；缺陷列表在类型标识旁展示已同步、未同步或同步失败状态，未勾选的缺陷只保存在平台内。
- **Manual Feishu Sync Action**: 缺陷预览顶部在未同步或同步失败时展示“同步到空间”按钮，可将此前未勾选的缺陷主动加入飞书同步队列；列表同步状态标识与缺陷类型标识统一为相同视觉规格。
- **Feishu Business Line Mapping**: 同步飞书缺陷时按 MCP `_business` 字段要求传递最终叶子选项 ID；TTmins 项目写入新增的 `TTMins` 叶子，ShortsWave Android/iOS 项目写入 `ShortsWave → 其他` 的叶子，并优先识别 `ShortsWave - TTmins` 为 TTMins，避免传入父级或查询结果结构导致层级校验失败。
- **TTmins Feishu Defect Naming**: TTmins 缺陷在飞书中的标题前缀改为 `[项目编号-日期-序号]`，例如 Dramix TTmins 的 `BUG-20260917-0001` 写为 `[A1181-20260917-0001]`；ShortsWave 继续使用原 `BUG-...` 前缀，查重同时兼容 TTmins 新旧命名，避免产生重复工作项。

### Changed
- **Field Mapping**: 飞书优先级按严重程度映射为 `S1→P0`、`S2→P1`、`S3/S4→P2`；版本和附件暂不自动同步，平台、问题现场和测试环境合并写入飞书缺陷描述。

## 2026-09-16

### Added
- **Batch Defect Submission**: 新建缺陷支持通过“添加”按钮录入多个标题，也支持粘贴 `1.xxx`、`2.xxx` 格式的多行编号列表并自动识别；多个缺陷共享当前表单配置，单次最多提交 50 条。后端采用统一事务校验与写入，任意一条失败时整体回滚，避免产生不完整批次。
- **Supplementary Evidence Attachments**: 新建与编辑缺陷时，可在“补充说明”区域通过快捷键直接粘贴或选择图片、文本、日志、JSON、PDF 等附件；图片以缩略图展示，文本与 PDF 支持居中弹窗预览。缺陷详情页同步采用相同的补充说明附件卡片与居中预览交互，不再单独分散显示附件；编辑页可移除已有附件，保存后同步删除服务器记录和文件。

### Changed
- **Defect Drawers UI Consistency & Header Actions Refinement**:
  - **新建缺陷记录抽屉（DefectFormDrawer）**：重塑顶部关闭按钮为 `32×32px` 标准化圆角方形微交互按钮，消除原先原生粗糙样式；彻底统一缺陷标题输入框与添加按钮体系，移除次级输入框多余的灰色外层包装框与双重背景，主输入框与次级输入框均严格对齐为 `40px` 高度、`10px` 圆角、一致字体（14px 500）、一致内边距与聚焦光晕；添加与删除按钮统一对齐为 `40×40px`（`10px` 圆角）方圆质感按钮；多标题状态下首行与次行自动展示一致的等宽数字序列徽标（`1`、`2`、`3`...），实现 100% 视觉一致与对称平衡。
  - **缺陷预览详情抽屉（DefectDetailDrawer）**：顶栏操作区整合刷新、编辑与关闭三联操作按钮，关闭按钮重构为与刷新按钮完全对称的现代方圆卡片式按钮（带温和柔红 Hover 状态与微按压反馈），彻底告别原先裸露粗糙的 X 按钮；同步补齐抽屉顶栏内边距与底边框规范，消除视觉割裂；修正刷新按钮交互动效，外框保持平稳不动，仅悬浮时内部箭头图标微旋转（-60°），加载状态下箭头平滑旋转，彻底消除容器旋转带来的生硬感。

## 2026-09-11

### Changed
- **Open Project Membership Model**: 项目权限取消受限模式，统一为开放查看；未加入项目的用户仅可查看，加入项目后按负责人、测试、开发、产品或只读角色控制操作。新增账号默认成员属性配置，成员加入项目时自动带入其测试、开发或产品属性，并可在项目内单独调整。测试人员具备完整缺陷生命周期操作权限，包括确认、解决、验证、关闭和重新激活。
- **Project-scoped Defect Workspace**: 缺陷管理标题旁新增全局项目选择器；切换后统一约束顶部质量指标、状态数量、缺陷列表、统计分析和自定义字段范围。当前项目也会自动带入新建缺陷表单，避免提交到其他项目。
- **Defect Submission Smart Defaults**: 新建缺陷选定项目后，按“提测版本 → 线上版本”的优先级自动填入发现版本，并同步环境、App 版本、项目平台和关联测试设备；新建时默认功能问题、当天解决日期、当前用户为验证人、测试环境与 WiFi，并新增 TTmins 平台选项。编辑已有缺陷时保留原有字段。
- **Defect Management UI Visual Revamp**: 重构缺陷管理主控制台视觉与排版，彻底清除历史遗留的 8px/9px/10px 极端微型字体，正文字号提升至 13px-14px，状态与辅助标签提升至 11px-12px；概览指标卡片增加左侧色彩指示线与悬浮响应；列表表格引入 S1-S4 严重度彩色指示条与处理人圆形头像胶囊。
- **Defect Detail Drawer Overhaul**: 缺陷详情抽屉升级为现代生命周期步进器（Stepper）连线导航；重现步骤增加独立数字序列卡片；实际结果与预期结果重构为浅红/浅绿双栏语义对比卡片；测试环境升级为芯片标签组；附件列表支持双列展示并完整显示文件大小与上传人。
- **Defect Form Drawer Polish**: 提交与编辑缺陷抽屉去除冷硬堆叠感，背景统一为微蓝浅灰（#f8fafc）并升级 16px 圆角悬浮卡片；四大分段引入个性化多色彩阶段徽标（科技蓝/暖日橙/青湖蓝/紫晶紫）；重现步骤支持交互式圆角卡片增删；实际结果与预期结果采用红/绿语义双栏输入卡片；输入框与文本域引入柔焦点辉光轮廓；主操作按钮升级为微渐变质感与悬浮升起动效。
- **Quality Stats Panel & Permissions**: 质量效能大盘环形图中心数据与图例字号优化，14 天趋势图底部日期升级为 11px 等宽可读字体；项目缺陷排行与处理人负载引入平滑进度条；项目权限与自定义字段配置面板去除微型字体并规范卡片层级。
