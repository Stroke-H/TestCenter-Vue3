# 斗兽棋 (Jungle Chess) 项目开发记录

本文件记录了斗兽棋模块从零到一的开发过程、核心逻辑及视觉优化历程。

## 1. 项目基础构建
- **技术栈**: Vue 3 + TypeScript + CSS Grid + Element Plus (Icons)。
- **路由集成**: `/ui_auto_jungle` 路径，Dashboard 已添加快速访问入口。
- **文件结构**:
  - `index.vue`: 游戏主容器、状态管理、胜利弹窗。
  - `ChessBoard.vue`: 核心棋盘组件（4x8 网格）。
  - `ChessPiece.vue`: 单个棋子渲染（3D 翻转、视觉动效）。
  - `useGameLogic.ts`: 纯逻辑状态机（洗牌、移动判定、胜负计算）。

## 2. 核心游戏规则
- **棋盘布局**: 传统的 4×8 斗兽棋变体。
- **棋子职级**: 象(8) > 狮(7) > 虎(6) > 豹(5) > 狼(4) > 犬(3) > 猫(2) > 鼠(1)。
- **捕食规则**: 
  - 大吃小或同级互吃。
  - **特例**: 鼠(1) 可以吃 象(8)；象(8) 不能吃 鼠(1)。
- **暗棋机制**: 
  - 开局所有棋子背面向上，通过翻开暗棋决定红蓝阵营。
  - 阵营按首个翻开棋子的颜色自动分配。

## 3. 视觉与交互设计 (UI/UX)
- **棋子重构**: 
  - 采用极简高端风，棋子为正圆形，移除数字和文字名称，突出精美动物头像。
  - 缩放动物图片 (115%) 并配合 `scale(1.15)`，确保护框不露白。
- **动画系统**: 
  - **平滑移动**: 基于 `Vue TransitionGroup` 的 FLIP 动画技术，实现棋子在网格间的滑动效果。
  - **吃棋特效**: 被捕食者执行缩放动画并平滑渐隐。
  - **3D 翻转**: 棋子背面到正面的 180 度翻转效果。
- **动态状态提示**: 
  - 顶部导航栏显示双方势力点。
  - 棋盘上方新增 **呼吸感文案提示**，实时反馈当前行动方。
  - 选中状态下棋子带有金色呼吸边框和上浮阴影。

## 4. 技术性修复记录
- **资源路径修复**: 修正了静态资源在多级目录下的相对路径解析错误（`../../` -> `../../../`）。
- **布局压缩修复**: 解决了棋子与背景格共用 Grid 坐标导致的“隐式行压缩”问题。通过 **双层 Grid 叠加技术**（`pieces-layer`）彻底解决了棋块被压扁的情况。
- **显示范围适配**: 优化了 `min(90vw, 70vh * 2)` 的计算公式并调整了容器 `overflow` 属性，确保 8 列棋子在各种屏幕下均完整可见。
- **高端素材集成**: 使用 AI 生成并集成了高端的“金色丛林神庙”作为棋子背面图片（`cover.png`），取代了原始的 Emoji 🌳 图案。

## 6. 联机版核心机制 (Networking)
- **Matching (匹配)**: 采用后端匹配队列，支持两名在线用户实时对局。
- **Synchronization (同步)**: 采用 P2P 直连思想，房主本地生成棋盘后全量同步至客端。所有走子、翻牌操作均实时双向转发。
- **Turn Control (回合控制)**: 基于首个翻开棋子的颜色决定阵营，严格拦截非己方回合或非己方阵营的交互动作。
- **Connection Management (连接管理)**: 具备完善的掉线处理与重连清理机制。
